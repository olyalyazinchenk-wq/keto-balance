## Процедура допуска
1. Владелец согласует состав карточек, базовый выход и проверенные аллергены.
2. Вносится запись в `RELEASED_RECIPE_APPROVALS` в `src/data/releasedRecipeIds.ts` с вычислением SHA-256 хеша карточки.
3. ID рецепта добавляется в массив `RELEASED_RECIPE_IDS`.
4. Скрипт сборки `scripts/export-release-catalog.mjs` генерирует официальный `dist/released-catalog.json`.

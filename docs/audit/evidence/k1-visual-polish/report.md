# K1 — визуальная полировка

## Область
Ветка `design/argon-ui-import`. Изменены только UI Food-First и добавлен `tests/frontend/food-visual-polish.test.cjs`. Математическое ядро, сервер, тарифы и данные рецептов не менялись. Коммита, push и production-деплоя не было.

## Результат
- Адаптивная шапка, переносы заголовков и кнопок; устранена минимальная ширина grid в Покупках. Добавлены внутренние отступы Рецепта и Покупок. Корневой overflow не скрывается.
- Рецепт получает фото из того же `photoForRecipe`, что Сегодня и Меню. Локальное фото, скругления, бейдж времени; fallback при отсутствии/ошибке изображения.
- Лента дней: scrollbar-width:none, -ms-overflow-style:none, WebKit display:none, scroll-snap-type:x mandatory.
- Сегодня: «Ритм дня». Статус «Приготовлено» соответствует всем отмеченным шагам рецепта; это не утверждение, что еда съедена. Сохраняется существующая семантика checkedSteps, без новой схемы хранения.
- Покупки: доступный progressbar с актуальным aria-valuenow и плавным зелёным заполнением. Учитывается существующий расчёт отмеченных/имеющихся дома продуктов.
- Активный кухонный таймер: тёмно-зелёная акцентная плашка, крупный отсчёт, адаптивные кнопки. reduced-motion отключает анимации.

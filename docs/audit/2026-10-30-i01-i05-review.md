## Остаточная граница I05: env-loader Vite

- `package.json:9` продолжает вызывать обычный `vite build`.
- `vite.config.ts:1–16` не задаёт отдельного env-каталога для frontend и не отключает загрузку env.
- В реально установленном Vite `node_modules/vite/dist/node/chunks/dep-BK3b2jBa.js:66485–66486` default envDir равен root, затем вызывается `loadEnv`.
- `34884–34909` перечисляет `.env`, `.env.local`, mode variants и читает содержимое имеющихся файлов.
- Дополнительная проба вызвала **только loader** на синтетическом `.env` в scratch: зарегистрирована одна попытка чтения, она остановлена trap до чтения содержимого. Это подтверждает поведение loader, а не доказывает факт прошлого чтения/утечки настоящего секрета.

Нельзя утверждать, что реальные секреты были опубликованы: это не проверялось и из указанных фактов не следует. Но исключение одного `bot_data.json` не доказывает выполнения запрета на чтение настоящих секретов всей цепочкой сборки.

**Узкое закрытие:** изолировать env-источник frontend build от реального backend `.env` либо выполнять проверку в allowlisted scratch-копии с исключительно synthetic env. Затем покрыть полный build lifecycle файловым перехватом для runtime data/секретных файлов, сохранив исходный dist. Не переносить вслепую `envDir:false` из донорского Vite 8: фактический основной Vite использует другую реализацию. Не читать/редактировать настоящий `.env`, не ослаблять проверки каталога и не менять формулы ради прохождения.

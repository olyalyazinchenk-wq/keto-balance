## Обязательные исправления

### F01 — покупки не пересчитываются по меню

**Приоритет: высокий. Evidence: source + browser reproduction.**

`src/App.tsx:449–452`: `handleRefreshShoppingFromMenu` только сбрасывает `shoppingNeedsRefresh` и передаёт прежние `shoppingItems`. Пересчёта состава/количеств нет.

Воспроизведение: Menu → заменить завтрак на творожный скрэмбл → Shopping → «Обновить список по меню». Сериализованный список до/после одинаков, stale меняется с `true` на `false`.

Исправление: пересчёт по актуальному меню через согласованную нормализацию ингредиентов, сохранение относящихся к новым позициям отметок. Не просто снять warning. Проверка должна сравнивать items до/после замены и не допускать сообщения об актуальном списке, когда он не пересчитан.

### F02 — ложный успех копирования

**Приоритет: высокий. Evidence: source + browser reproduction.**

`src/components/kb/RecipeAndShoppingScreens.tsx:564–576`: `writeText(...).catch(() => {})`, затем безусловный `setCopiedNotice(true)`. При отказе Clipboard API интерфейс сообщает успех.

Воспроизведение: в отдельном браузере подменить clipboard.writeText на Promise.reject; нажать «Скопировать список». «Скопировано» появляется. Никакая реальная отправка при этом не выполнялась.

Исправление: дождаться успешного Promise; для reject/отсутствующего API показать ошибку или честный ручной fallback. Добавить оба отрицательных теста.

### F03 — фото не связано с выбранным рецептом

**Приоритет: средний. Evidence: source + browser reproduction.**

`src/components/kb/TodayAndMenuScreens.tsx:67–80`: один `/media/food-first/hero.webp` передаётся для любого leadRecipe. Изменение alt не меняет содержимое фотографии.

Воспроизведение: заменить breakfast `kb-rec-eggs-avocado` на `kb-rec-cottage-scramble`, открыть Today. Заголовок и меню изменились; src остался прежним.

Исправление: явное соответствие recipe ID → проверенный asset. При отсутствии подходящего изображения — честный fallback, не фото другого блюда. Повторить проверку после смены дня и замены рецепта.

### F04 — новый дизайн пока только у Today

**Приоритет: средний; не блокирует отдельный G0, блокирует единый UI-путь. Evidence: source + screenshots/browser.**

- `src/index.css:48–52,129–142`: display-шрифт старых экранов — Georgia/serif.
- `src/components/kb/TodayAndMenuScreens.tsx:163–179`: «РЕДАКЦИОННОЕ РАСПИСАНИЕ», большие старые заголовки.
- `RecipeAndShoppingScreens.tsx`: прежние номера секций/рейлы, длинное название рецепта, схемная тарелка.
- `AppShell.tsx:72` включает новую оболочку только для Today.

Исправление: перенести принятый цифровой визуальный словарь в Menu/Recipe/Shopping и общую оболочку. Не перекрашивать старую композицию и не создавать ещё одну альтернативу Today.

### F05 — неподтверждённые обещания и числовые характеристики блюда

**Приоритет: высокий для пользовательской публикации. Evidence: source + visible Recipe UI.**

`src/components/kb/RecipeArtwork.tsx:20–32`: жёстко заданы «5 ч сытости · без тяги к сладкому», «0 скачков сахара», проценты состава и пояснения о «сжигании запасов». В проверенном рецепте соответствующие обещания видны пользователю. `RecipeAndShoppingScreens.tsx:134–136` также отображает универсальные ~230/~460 г.

Наличие надписи «КБЖУ уточняется» не подтверждает эти отдельные характеристики. В проверенном коде нет связи этих обещаний с согласованной методологией/расчётом. Этот аудит не утверждает медицинскую истинность или ложность каждого тезиса; фиксируется отсутствие основания для их приёмки в данном продукте.

Исправление: убрать несогласованные обещания и числовые характеристики из UI или предоставить утверждённые источники/данные и методологию. Не добавлять фиктивные результаты как способ сделать интерфейс убедительнее.

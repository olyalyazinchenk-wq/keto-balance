# Тест хуков: кодовая анимация как эталон (baseline)

Дата: 28.10.2026. Статус: **хуки отрендерены, ждём постинг**.
Скрипты: `scripts/render_code_hooks.py` (основной набор), `scripts/render_hooks.py` (контроль на фото).
Файлы: `media/hooks/code/` (10 шт., 3 с, 1080×1920, 30 fps), `media/hooks/` (контроль на фото).

## Зачем этот тест

Проверяем гипотезу «POV-видео из world-модели даёт прирост удержания» **без** платной генерации.
Сначала фиксируем планку: сколько удержания даёт бесплатная кодовая анимация. Если платная
генерация не бьёт эту планку на 25–30% — деньги в неё не идут (kill-switch).

## Почему базовый набор — код, а не фото

В `media/assets/` и `media/frame_*` лежат кадры, которые **противоречат** заявлению «кето»:

| Файл | Что на кадре | Проблема |
|---|---|---|
| `scene1_hook.jpg`, `frame_02_hook.jpg` | стопка сырников с сиропом и бананом | банан и сироп — углеводы |
| `scene2_ing.jpg`, `frame_10_ing.jpg` | крепы с кремом и ягодами | блины = мука, а подпись обещает кокосовую муку |
| `scene3_bake.jpg`, `frame_22_bake.jpg` | белый торт с шоколадной глазурью | визуально сахарный десерт |
| `scene4_money.jpg`, `frame_32_kbju.jpg` | тако с нутом + подпись «Углеводы: 4.8 г» | нут не даёт 4.8 г углеводов |

Показывать такие кадры с надписью «кето» — риск доверия и репутации (см. инварианты честности
в `AGENTS.md`). Поэтому базовый набор — чистая типографика; фото-версии оставлены как контроль
и в канал не идут.

## Что заменяет отсутствующий бот

Бот не запущен, поэтому воронку «ролик → бот → подписка» измерить нельзя. Меряем **прокси-метрики
этапа «охват и интерес»** в канале, где трафик уже есть:

| Метрика | Где смотреть | Зачем |
|---|---|---|
| Просмотры за 24 ч | статистика поста в канале | базовая заметность |
| Реакции на 100 просмотров | иконка реакций под постом | «зацепило / не зацепило» |
| Репосты и пересылки | статистика поста | виральность хука |
| Переходы по ссылке | статистика канала (если включена) | клик-интерес до бота |
| Удержание первых 3 сек | только если дублируем в Reels / Shorts / TikTok | прямой замер хука |

Прямого «удержания 3 секунд» в канале Telegram нет — поэтому либо добавляем площадку с аналитикой
(Shorts/Reels), либо считаем прокси: доля досмотров и реакции.

## Порядок теста (7–14 дней)

1. **День 1–3:** постим 5 хуков группы A (боль/ошибка) — по одному в день, в одно и то же время.
2. **День 4–6:** 3 хука группы B (выгода/продукт).
3. **День 7–8:** 2 хука группы C (проверка/вопрос).
4. Каждый пост — 3-секундный ролик + текстовое продолжение в сообщении (1 абзац) + призыв
   «продолжение в канале». Никаких ссылок на неработающий бот.
5. Замер — через 24 часа после поста, в одну таблицу `media/hooks/test_sheet.csv`.

## Критерий отсечения (kill-switch)

- Эталон = средние реакции/просмотры и доля досмотров по группе A (код-анимация).
- Платная видеогенерация (Genie 4 / Veo / Kling) запускается только если её вариант даёт
  **+25–30% к удержанию первых 3 секунд** и не ухудшает реакции/просмотры.
- Если прироста нет — видеогенерация отключается, бюджет остаётся в кодовых инструментах.
- Отдельное условие: любой платный прогон допустим только при подтверждённой доступности API
  и оплате по факту. Сейчас Genie 4 — research preview: Project Genie только для Google AI Ultra,
  сессия исследования мира 60 секунд, API — по приглашению для ранних партнёров.

## Что нужно снять, чтобы фото-набор стал честным

1. Руки режут авокадо / стейк / огурец на доске — вид сверху, 10 секунд.
2. Готовая тарелка: белок + зелень + жир, без хлеба и круп.
3. Этикетка реального продукта с БЖУ крупным планом.
4. Кухонные весы с продуктом на них (для сюжета про подсчёт).

Из этих 4 футажей собирается POV-набор без генерации — и он уже будет честным.

# Изображения и шрифт

Все пять новых изображений — фотоиллюстрации, созданные встроенным image_gen 6 ноября 2026. Они не выдаются за фотографии приготовленных автором блюд: в интерфейсе используется alt «Фотоиллюстрация». Исходные PNG остаются в generated_images Codex; в приложении используются сжатые WebP.

| ID | Файл | Проверенное содержание |
|---|---|---|
| k1 | eggs-bacon-spinach.webp | Яйца, бекон, шпинат, сливочное масло; без авокадо и сыра |
| k2 | omelet-cheese-herbs.webp | Омлет с сыром, сливками, укропом и петрушкой |
| k3 | baked-cottage-cheese.webp | Запечённые сырники из творога с кокосовой мукой и сметаной |
| k4 | avocado-flatbread.webp | Лепёшки из кокосовой муки и яиц с размятым авокадо |
| k5 | egg-muffins.webp | Яичные маффины с перцем, шпинатом и сыром |

Промпты: естественный дневной свет, домашняя еда, светлая керамическая тарелка, светлый стол, без текста, лишних украшений и ингредиентов вне перечисленного состава. Каждый результат осмотрен перед подключением. k5: название каталога содержит ветчину, которой нет в его составе; изображение соответствует составу. Название не исправлялось в рамках дизайна.

Существующий hero.webp сохранён только для kb-rec-eggs-avocado; ошибочное использование для k1 устранено.

Golos Text скачан из https://github.com/google/fonts/tree/main/ofl/golostext. Локальный переменный TTF и SIL OFL 1.1 находятся в public/fonts/. Сетевых запросов к Google Fonts при открытии приложения нет.

Референс направления: reference.png — третий показанный вариант ImageGen. Декоративные листья не переносились; использованы рабочая шапка, честное обозначение тестовых данных и реальные названия блюд.

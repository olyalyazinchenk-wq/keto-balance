# Видеоинструкция КетоБаланса

24 секунды, 1080×1920, 30 кадров/с. Четыре действия: собрать календарный месяц → заменить блюдо → купить продукты на неделю → готовить по шагам с таймером.

- [Полная текстовая инструкция](guide.ru.md) доступна без звука и воспроизведения видео.
- [Исходник композиции](index.html), [визуальные правила](DESIGN.md).
- Готовый файл: [`public/media/how-to-month-20261113.mp4`](../../../public/media/how-to-month-20261113.mp4).
- Никаких внешних загрузок или ИИ при воспроизведении: снимки, Golos Text и GSAP хранятся локально.

## Основание

Настоящие экраны frozen-сборки **8be43f00ba6d26b3**, исходник приложения **3568cc7**, каталог **666c79712f63128f**. Сборка выбрана через сохранённый `build-release.json`, без обращения к меняющемуся `latest`.

Снимки сделаны 14.11.2026 (МСК) через изолированный HTTP-сервер 127.0.0.1:18193, отдельную тестовую SQLite и синтетический профиль. Месячный режим включён через тестовый demo-платёж, реальных денег и Telegram-сообщений нет. Это браузерный снимок настоящего приложения, не запись с физического телефона. Существующие рецепты и отметки «КБЖУ уточняется автором» сохранены. Числа нового редакторского пакета в интерфейс не подставлялись.

| Время | Действие | Экран |
|---|---|---|
| 0–6 с | Выбрать месяц и настройки | Месячное меню с неделями и днями |
| 6–12 с | Заменить блюдо | Окно «Выберите блюдо» |
| 12–18 с | Купить продукты на неделю | Неделя 2, обновлённая корзина |
| 18–24 с | Готовить по шагам | Отмеченный шаг и запущенный таймер |

Видео намеренно без звука: все действия написаны крупно, полная инструкция лежит рядом. Таймер в снимке — статичный кадр реального запущенного таймера, а не работающий таймер внутри видео. Его фоновый сигнал не гарантируется; ограничение видно в ролике и текстовой инструкции.

## Проверка и повторная сборка

Версия HyperFrames закреплена **0.9.41**, GSAP **3.15.0**. Для этой Windows-машины `run-video.ps1` использует исправный npm CLI Hermes, поскольку глобальный npm ранее не запускался. Команды не публикуют проект и отключают телеметрию:

```powershell
.\run-video.ps1 -Action check
.\run-video.ps1 -Action snapshot
.\run-video.ps1 -Action render
```

В [verification.json](verification.json) — SHA-256 входов и результата, итог проверок и ограничения. Устойчивые кадры и переходы просмотрены отдельно. Плавное перекрытие сцен помечено как намеренное: это не разрешение на обрезку текста; размеры и контраст по-прежнему проверяются. Длинные неподвижные отрезки помечены как время для чтения.

Подключение ролика в приложение, публикация и приёмка — отдельные действия координатора. Frozen-сборка приложения этим пакетом не меняется.

# Референсные дизайн-системы (внешние)

Источник: **OpenDesign** — https://open-design.ai (код и каталог: https://github.com/nexu-io/open-design),
лицензия Apache-2.0. Файлы скопированы без изменений, только для внутренней работы над проектом.

Почему они здесь: OpenDesign публикует дизайн-системы в формате `DESIGN.md` — машиночитаемая
спецификация (палитра, шкала типографики, сетка, компоненты, motion, антипаттерны, гайд для агента).
Это позволяет передавать дизайн-идею агенту не скриншотами, а правилами.

## Что взято

| Файл | Система | Чем полезна нам |
|---|---|---|
| `DESIGN-kami.md` | kami (紙 / 纸), Editorial & Print | Ближе всего к нашему направлению: тёплая бумага `#f5f4ed`, единственный хроматический акцент, **четыре уровня текста и никакого пятого**, запрет курсива, табличные цифры, паттерн заголовка секции с левой линейкой |
| `DESIGN-atelier-zero.md` | Atelier Zero, Editorial · Studio | Дисциплина печатного журнала: метаданные выпуска, римские правила секций, уголки-кроп-марки и «Plate Nº» на изображениях, боковые рейлы, ровно один акцент на экран, правило «больше драмы = крупнее кегль, а не больше цвета» |

## Как использовать

1. Агент (Gemini 4 Argon) получает эти файлы как вложения к заданию.
2. В задании явно сказано: брать **механику**, не эстетику. Палитру и бренд оставляем свои.
3. Любое отклонение от правил фиксируется в `docs/design/art-directions.md` с причиной.

## Чего не делаем

- Не копируем коралловый акцент Atelier Zero и его коллажную графику — это другая марка.
- Не переносим лицензионные ассеты, только текстовые спецификации.

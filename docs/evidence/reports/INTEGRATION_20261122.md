При смене сессии сбрасываются и кэш, и видимые карточки. Ответ API помечен `private, no-store`, `Vary: Authorization`. Допуск материалов не менялся. По истечении срока следующий вход снова обращается к серверу. Пользователь может повторить запрос после ошибки.

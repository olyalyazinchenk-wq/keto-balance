## Logic Chain

В «Ещё» добавлен заметный вход «Мой прогресс · вес и объёмы» перед советом/лайфхаками и тарифами. Старый адрес diary также открывает этот экран. Возраст указывается целым числом 18–120; минимально необходимые поля — дата и один замер. Вес в кг, окружности груди/талии/бёдер в см, десятичная запятая поддерживается. Пустые поля не считаются нулём. Дата не может быть будущей; календарный день определён по Москве.

История хранится на существующем сервере отдельно по Telegram-сессии клиента. Сравнение показывает изменение каждого показателя относительно его первого заполненного замера; график веса использует замеры по порядку дат (точные даты/значения доступны в истории). Нет целевых медицинских значений или обещаний результата. Поиск добавок и все 36 изображений рецептов унаследованы от #51/#50.

Существующую дату нельзя молча заменить неполной формой: сначала требуется «Изменить», загружающее все показатели. После 409/обновления также требуется открыть свежую запись; конкурентные изменения не затираются повтором старой формы. Удаление записи требует явного подтверждения в интерфейсе. Состояние формы сохраняется при возврате назад, сбрасывается при смене сессии/аккаунта. Замеры не сохраняются в localStorage и не направляются в стороннюю аналитику.

API `GET/PUT /api/progress`, `DELETE /api/progress/{date}?expected_revision=N`; Bearer-session обязательна, user_id из тела запрещён, чужие селекторы отклоняются. CAS атомарен (`BEGIN IMMEDIATE`); PUT полностью заменяет явно редактируемую запись даты. Новые таблицы `progress_profiles` и `progress_entries` добавляются идемпотентно, существующие профили не переписываются. Согласие `body_progress/v1` фиксируется в существующем журнале атомарно с записью. Экспорт/удаление аккаунта охватывают замеры; Cache-Control no-store. Текст приватности дополнен.

## Изменения по критериям приёмки

1. Today, More, меню и форма используют точное название «Настройки питания». Кнопки открывают ту же рабочую форму; выбранные исключения сохраняются. «Правила кето» — отдельная раскрываемая справка по продуктам, ограничениям количества, обычным заменам и учёту углеводов/порций. Справка не меняет настройки и не объявляет продукты медицински запрещёнными для всех.
2. Тестовые12состояний и сброс прототипа находились в старых design/argon-архивах, которые не входят в main.tsx и release dist. Исторические исходники сохранены; недоступность этих панелей проверена в актуальном More и в реальном внешнем JS. Постоянный test-catalog banner убран. Полезные saving/error/conflict/shopping-stale сообщения сохранены только по соответствующему состоянию и написаны простыми словами. Из ошибок убраны внутренние ID рецепта/каталога; клиент не получает кнопку очистки прототипа.
3. Первый вход больше не заявляет о локальной тестовой БД и непередаче вопросов во внешние сервисы. Краткая информация о данных соответствует сохранению профиля/меню/покупок/обращений на сервере. Обещаний абсолютной защиты нет. Тариф сохраняет990₽/30дней; закрытая оплата обозначена честно. demo_user/previewprop не открывают демонстрационные платежи на внешнем хосте. Полные юридические документы перед публичным запуском остаются отдельным условием, краткая справка не выдаётся за утверждённую политику.
4. Новые планы/замены только keto. Старый профиль или план другого режима не пересобираются незаметно: пользователь видит сохранённый рацион и предложение явно создать новое кето-меню. До этого замена/пересборка скрыты и защищены обработчиками. Исключения и собственные продукты наследуются. API запрещает changed non-keto menu даже владельцу. Для неизменного прежнего плана с неизменным нормализованным профилем разрешены день/отметки; новая порция/рецепт/каталог/ограничение проходят прежние проверки. None/[] отсутствующих противопоказаний считаются эквивалентными. Рецепты/архивы не удалялись по ID и не получали автоматического нового допуска.
5. Неподтверждённые КБЖУ численно не публикуются. В тарелке и подсказке используется обычная фраза о неподтверждённой пищевой ценности; формулы/индивидуальные нормы не менялись.

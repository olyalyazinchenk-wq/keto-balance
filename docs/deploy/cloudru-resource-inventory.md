# Инвентаризация тарифицируемых ресурсов Cloud.ru Evolution
## Регламент предотвращения непредвиденных расходов и отрицательного баланса

В облачных инфраструктурах уровня Enterprise (включая Cloud.ru Evolution) остановка или выключение виртуальной машины **не останавливает списания средств**.

Данный документ содержит полный перечень ресурсов, которые продолжают списывать деньги после остановки сервера, и правила их гарантированного полного удаления.

---

## 1. Сводная таблица тарифицируемых ресурсов

| Категория ресурса | Что происходит при выключении сервера (`stop`) | Что происходит при удалении только сервера (`delete VM`) | Как предотвратить списания (0 ₽) |
|---|---|---|---|
| **Виртуальная машина (vCPU + RAM)** | Списания за CPU/RAM останавливаются | Ресурс уничтожен, списаний нет | Удалить инстанс |
| **Системный диск (Boot Volume)** | **Продолжает тарифицироваться** (~9–12 ₽/ГБ/мес) | **Остаётся в хранилище**, если не выбрана галочка «Удалить диск» | Принудительно удалить блочный том в разделе «Диски» |
| **Дополнительные диски (Data Volumes)** | **Продолжают тарифицироваться** | **Остаются в хранилище** и продолжают начислять долг | Найти и удалить все тома со статусом `available` или `in-use` |
| **Снимки дисков (Snapshots)** | **Тарифицируются** за каждый сохранённый гигабайт | **Сохраняются навсегда**, пока не удалены вручную | Удалить все снимки в разделе «Снимки дисков» |
| **Публичные IP (Floating IP)** | **Тарифицируются** (~150–250 ₽/мес за штуку) | **Остаются закреплёнными за аккаунтом** и тарифицируются | Освободить (Release) публичный IP обратно в пул провайдера |
| **Виртуальные маршрутизаторы (VPC Router / NAT)** | **Тарифицируются** (плата за маршрутизацию) | Сохраняются в составе частной сети проекта | Удалить шлюзы и внешние интерфейсы |
| **Объектное хранилище S3 (Object Storage)** | Не зависит от сервера | Бакеты и файлы сохраняются и тарифицируются | Очистить и удалить бакеты, если создавались |
| **Резервные копии (Cloud Backup)** | Тарифицируются по объёму | Хранятся по расписанию ретеншна | Удалить цепочки автоматических бэкапов |

## 2. Где проверять ресурсы в личном кабинете Cloud.ru

Перед завершением использования гранта обязательно проверьте следующие разделы консоли:

1. **Evolution Compute -> Виртуальные машины (Instances):**
   - Список должен быть пуст (`0 серверов`).
2. **Evolution Compute -> Диски (Disks / Block Storage):**
   - Список дисков должен быть пуст (`0 дисков`).
   - Если в списке есть диски со статусом `available` (свободен) или `error` — выберите их и нажмите **«Удалить»**.
3. **Evolution Compute -> Снимки (Snapshots):**
   - Проверьте отсутствие старых снапшотов.
4. **Виртуальные сети (VPC) -> Публичные IP (Floating IPs):**
   - Список закреплённых IP должен быть пуст (`0 IP`).
   - Если IP отображается в статусе `DOWN` или `Unassociated` — выберите действие **«Освободить IP»** (Release).
5. **Объектное хранилище (Object Storage):**
   - Проверьте раздел бакетов. Если бакеты не используются — они должны быть удалены.

## 3. Критический порог и правило закрытия

1. **За 14 дней до окончания гранта (день 46):**
   - Проводится ревизия проекта и текущей выручки.
   - Если бот остаётся в Cloud.ru на платной основе — согласуется бюджет и настраивается лимит расходов.
   - Если бот переносится на фиксированный VPS (300–400 ₽/мес) — выполняется выгрузка зашифрованной копии базы данных.
2. **За 3 дня до окончания гранта:**
   - Выполняется финальный зашифрованный бэкап.
   - Запускается скрипт контролируемого удаления всех ресурсов (`ops/cloudru-teardown.sh`).
   - Проводится визуальная сверка по чеклисту выше: во всех вкладках консоли должно быть **0 активных сущностей**.

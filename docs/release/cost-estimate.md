## 4. Обязательные условия вывода средств (Checklist для Ольги)

1. **Telegram-аккаунт создателя бота**: должен быть привязан к кошельку **Fragment** (через TON Space или Tonkeeper).
2. **Лимит и порог вывода**: Минимальный баланс для вывода на Fragment составляет **1 000 Stars**.
3. **Период холда (21 день)**: Согласно правилам Telegram Bot Payments, полученные звёзды доступны к выводу через 21 день после совершения платежа пользователем (защита от чарджбэков).
4. **Конвертация**: Вывод происходит в криптовалюте **TON**, которая затем свободно обменивается на рубли через P2P-маркет в Telegram Wallet на карту любого российского банка (Т-Банк, Сбер, СБП).

# Руководство по домашнему показу Keto Balance (Home Pilot Runbook)

> **Для кого:** Ольга Зинченко (автор и нутрициолог) и операторы проекта.  
> **Цель:** Простое, надёжное и безопасное управление домашним показом Mini App и Telegram-бота без технических сложностей, без реальных платежей и без риска нарушить работу других сервисов.  
> **Дата актуализации:** 1 ноября 2026 г.  
> **Статус:** Home Pilot / Контролируемый личный показ.

---

## 1. Главные правила безопасности и спокойствия

1. **Никаких реальных списаний:** В режиме домашнего показа все боевые платежи аппаратно и программно отключены. Можно спокойно нажимать любые кнопки — деньги с карт или баланса Telegram Stars не спишутся.
2. **Личный доступ только для Ольги:** Mini App открывается только в личном диалоге с ботом `@keto_balance_userbot` для пользователя с Telegram ID `1084557944` (Ольга). Посторонние запросы отклоняются сервером автоматически.
3. **Бережное отношение к НутриОК:** На компьютере уже работает бот НутриОК (`WellnessBot`). Домашний показ Keto Balance развёрнут на изолированном порту **`18081`** и никак не пересекается с портами `8000`, `4387`, `8090`, `10808`, `10809`.
4. **Один легитимный слушатель:** Получение обновлений для НутриОК ведётся строго через планировщик Windows `WellnessBot`. Второй слушатель никогда не запускается.

## 2. Управление в один клик

Все операции управления выполняются короткими командами через PowerShell:

### А. Запуск служб показа
```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\HP\Keto-balance\ops\start-keto-balance.ps1"
```
Что происходит:
- Проверяется окружение Python (`.venv-p0`).
- Запускается сервер на изолированном порту `18081` с отдельной базой данных показа.
- Запускается защищённый туннель `localhost.run` (с проверкой SSH-ключа).
- В личный чат Ольги в Telegram отправляется персональная кнопка меню «🥑 Открыть Кето Баланс».

### Б. Проверка состояния (Всё ли работает?)
```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\HP\Keto-balance\ops\status-keto-balance.ps1"
```
Скрипт покажет:
- Состояние сервера на порту 18081 (PID процесса, версию сборки).
- Внешний адрес туннеля HTTPS.
- Статус Telegram-бота.
- Время последнего бэкапа базы данных.

### В. Настройка автозапуска при включении компьютера
Чтобы показ автоматически запускался при каждом входе в Windows и сам восстанавливался при случайных сбоях:
```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\HP\Keto-balance\ops\setup-home-pilot-task.ps1"
```
- Проверить статус задачи: `powershell -File ops/setup-home-pilot-task.ps1 -Status`
- При необходимости удалить автозапуск: `powershell -File ops/setup-home-pilot-task.ps1 -Remove`

## 3. Сквозной маршрут проверки для Ольги (User Journey)

Откройте диалог с ботом `@keto_balance_userbot` в Telegram и пройдите по основным шагам:

### Шаг 1. Приветствие и запуск
- Введите команду `/start`.
- Бот пришлёт тёплое приветствие от нутрициолога Ольги с описанием возможностей (расчёт нормы воды, рецепты, список покупок, протокол «Антисрыв»).
- Нажмите кнопку «🥑 Открыть Кето Баланс» внизу экрана для открытия Mini App.

### Шаг 2. Экран знакомства (Start Gate)
- Выберите комфортный формат: **Кето-рацион** (мягкий баланс с овощами) или **Карнивор** (строго животный рацион).
- Обратите внимание на обязательные пункты:
  - Чекбокс **«Мне есть 18 лет»** (подтверждение возраста и понимания бытового характера сервиса без отмены назначений врача).
  - Чекбокс **«Согласие на обработку персональных данных»** (152-ФЗ).
- Кнопка «Продолжить» станет активной только после отметки обоих пунктов.
- Под блоком отображается уведомление о согласовании финального текста оферты.

### Шаг 3. Настройка меню и исключений
- Перейдите в настройки ограничений рациона.
- Проверьте исключение ключевых аллергенов:
  - Яйца, молочные продукты, рыба, орехи.
- Проверьте исключение нелюбимых продуктов:
  - Печень и субпродукты, грибы, авокадо, лук, брокколи, перец, морепродукты.
- Блюда с исключёнными ингредиентами автоматически убираются из подбора меню.

### Шаг 4. Меню дня и замена рецептов
- На экране «Меню» отображаются готовые приёмы пищи на день (завтрак, обед, ужин).
- Нажмите «Заменить блюдо», чтобы быстро выбрать альтернативный рецепт, не нарушая ограничений.

### Шаг 5. Карточка рецепта и таймер у плиты
- Откройте любой рецепт.
- Переключите количество порций: **1 порция** или **2 порции** (количество ингредиентов пересчитывается мгновенно).
- В шагах приготовления нажмите **«Запустить таймер»** (например, 15 минут) — запустится кухонный таймер прямо на экране смартфона с тактильным откликом при завершении.
- Внизу рецепта изучите блок **«Допустимые замены»** и **«Правило хранения»**.

### Шаг 6. Список покупок в супермаркете
- Перейдите на вкладку «Покупки».
- Все продукты сгруппированы по отделам магазина:
  - *Мясо, птица и рыба*
  - *Яйца и молочное*
  - *Овощи и зелень*
  - *Масла и бакалея*
- Отметьте то, что уже есть дома, нажав «Уже дома».
- Нажмите **«Скопировать список»** — готовый аккуратный список скопируется в буфер обмена для отправки в заметки или близким.

## 4. Чистота формулировок и забота о здоровье

Во всех текстах и материалах обоих проектов соблюдается главный медицинский принцип:
- Сервис носит **информационно-бытовой и консультационный характер**.
- Нутрициология помогает наладить сытное и здоровое питание, но **не заменяет врача**, не ставит диагнозы и не отменяет лекарственную терапию.
- При наличии хронических заболеваний, беременности или приёме рецептурных препаратов пользователю прямо рекомендуется предварительная очная консультация специалиста.
- Никаких ложных заверений о «100% гарантированном похудении» или «чудодейственном исцелении».

## 5. Резервное копирование и защита данных

База данных SQLite работает в режиме повышенной надёжности (WAL):
- Резервная копия создаётся утилитой:
  ```powershell
  & "C:\Users\HP\Keto-balance\.venv-p0\Scripts\python.exe" scripts/backup_db.py
  ```
  Копия сохраняется в `backups/` с расчётом SHA-256 контрольной суммы и метаданных.
- Проверка восстановления:
  ```powershell
  & "C:\Users\HP\Keto-balance\.venv-p0\Scripts\python.exe" scripts/restore_db.py backups/<файл_копии>.db --target <путь_к_новой_бд>
  ```
- В ходе инженерных испытаний проверено: **10 из 10 таблиц восстанавливаются с абсолютной точностью (0% потерь данных, PRAGMA integrity_check = OK)**.

## 6. Что делать при вопросах или неполадках

| Симптом | Причина | Что сделать |
|---|---|---|
| Mini App не открывается в Telegram | Обрыв туннеля `localhost.run` | Запустите `powershell ops/status-keto-balance.ps1` — туннель восстановится автоматически. |
| Telegram выдаёт ошибку авторизации | Вход выполнен с другого аккаунта | Доступ разрешён только для Telegram ID `1084557944` (Ольга). |
| Нужно перезагрузить службы | Плановое обновление | Запустите `powershell ops/start-keto-balance.ps1` — скрипт корректно обновит запущенные процессы. |
| НутриОК не отвечает | Проверка статуса фонового сервиса | Выполните `Get-ScheduledTask -TaskName WellnessBot`. Задача всегда должна быть в статусе `Running`. |

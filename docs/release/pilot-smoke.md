# Программа приёмочного тестирования пилота (Pilot Smoke Checklist)

## Сквозной пользовательский сценарий (4 экрана Food-First)

### Экран 1. «Сегодня» (Today & Onboarding)
- [ ] **18+ Подтверждение:** Чекбокс подтверждения совершеннолетия обязателен для разблокировки кнопки генерации плана.
- [ ] **Настройки рациона:**
  - Выбор подхода к кето (Классическое, Мягкое/Lazy, Циклическое).
  - Выбор ограничений (без молочки, без орехов, без яиц, без свинины, без рыбы/морепродуктов, без глютена).
  - Лимит времени приготовления (15, 30, 45, 60 мин).
  - Количество приёмов пищи в день (2, 3 или 4).
- [ ] **Генерация меню:** Нажатие «Сформировать меню на 3 дня» генерирует меню из допущенного каталога рецептов, полностью удовлетворяющее выбранным ограничениям и лимиту времени.

### Экран 2. «Меню» (3-дневный план)
- [ ] **Навигация по дням:** Переключение вкладок «День 1», «День 2», «День 3». Выбранный день сохраняется в сессии.
- [ ] **Карточки блюд:** Отображение приёмов пищи (Завтрак, Обед, Ужин) с КБЖУ, временем приготовления и тегами.
- [ ] **Замена рецепта:**
  - Нажатие кнопки «Заменить» открывает модальное окно с альтернативными кандидатами.
  - Список кандидатов отфильтрован по текущим ограничениям пользователя и времени готовки.
  - Выбор кандидата «Поставить в план» обновляет приём пищи и автоматически сохраняет новое состояние на сервере.

### Экран 3. «Рецепт» (Детальная карточка)
- [ ] **Переход в рецепт:** Нажатие на карточку блюда открывает детальный экран рецепта с точным ID.
- [ ] **Ингредиенты и шаги:**
  - Список ингредиентов с точными граммовками.
  - Пошаговые инструкции приготовления с возможностью отметки выполненных шагов.
- [ ] **Интерактивный таймер:**
  - Кнопка таймера запускает обратный отсчёт времени приготовления.
  - Поддерживаются пауза, сброс и звуковое/визуальное уведомление.
- [ ] **Возврат:** Кнопка «Назад» возвращает пользователя в меню на тот же день без потери контекста.

### Экран 4. «Покупки» (Smart Shopping List)
- [ ] **Умная агрегация:** Ингредиенты из всех блюд выбранного меню суммируются в единые канонические позиции с совместимыми единицами измерения (г, мл, шт.) без дубликатов.
- [ ] **Масштабирование порций:** Переключение коэффициента порций (1× / 2×) корректно пересчитывает количества ингредиентов.
- [ ] **Отметка купленного:** Чекбоксы «Куплено» вычеркивают позицию и обновляют прогресс-бар; состояние сохраняется на сервере.
- [ ] **Пользовательские позиции:** Поле добавления своего товара позволяет внести произвольную позицию (например, «Кокосовые сливки») и сохранить её в списке.
- [ ] **Копирование:** Кнопка «Скопировать список» копирует читаемый текстовый список продуктов в буфер обмена.

---

## Проверка персистентности и безопасности
- [ ] **Серверное сохранение:** Все изменения (настройки, меню, чеки покупок, кастомные товары) отправляются через очередь сохранения с оптимистической блокировкой CAS (HTTP 409 при конфликте версий).
- [ ] **Восстановление в новой сессии:** Закрытие вкладки/браузера и повторное открытие со свежим `BrowserContext` восстанавливает полное актуальное состояние с сервера.
- [ ] **Изоляция пользователей:** Пользователь B не имеет доступа к данным пользователя A (HTTP 403 / 401).

## Личная поддержка Ольги
- [ ] **Доступность экрана помощи:** Вкладка/кнопка «Помощь» доступна на любом этапе, включая экран настроек до завершения онбординга.
- [ ] **Прямая ссылка:** Кнопка «Написать Ольге» открывает диалог `https://t.me/keto_balance_userbot?start=question`.
- [ ] **Честный статус отправки:** Сохранение тикета в форме фиксирует статус в локальной БД без ложных заявлений об отправке в Telegram.

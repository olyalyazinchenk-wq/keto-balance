## 3. Политика продления, отмены и возвратов

1. **Автопродление:** Только при явном информировании пользователя в интерфейсе Telegram Payments.
2. **Отмена:** Пользователь может отключить продление в любой момент через настройки бота Telegram или меню управления подписками Telegram. Оплаченный доступ сохраняется до конца текущего 30-дневного периода.
3. **Возвраты (Refund):**
   - Запрос на возврат подаётся через `/paysupport` или личный контакт нутрициолога.
   - Администратор бота может выполнить возврат транзакции через Bot API `refundStarPayment`.
   - При подтверждении возврата Telegram Stars возвращаются на баланс пользователя, а статус подписки переводится в `refunded` с фиксацией в журнале заказов.

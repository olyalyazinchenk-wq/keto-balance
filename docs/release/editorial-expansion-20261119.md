# Расширение КетоБаланса — контрольная точка 19 ноября

Рабочая ветка feat/keto-editorial-catalog-20261118 идёт поверх PR #39. Продуктовый коммит a117247. При проверках используются временные данные. Сборка на сервере и телефонный сбой остаются отдельной задачей приёмки.

## Готово в ветке

- Правила кето на главной, раздел замен привычных продуктов и карточка о сахарозаменителях. В новых меню и заменах клиент и сервер проверяют названия ингредиентов на молоко и мальтит, включая код E965. В проверку входят названия растительных продуктов, обозначенных «молоко», согласно трактовке запрета в ТЗ. Проверка маркировки составных покупных ингредиентов остаётся частью ручного допуска.
- Генерация и замены сверяют сумму поля nc на личную порцию с пределом 50 г. При генерации учитывается запас на оставшиеся приёмы пищи. Точные числа в интерфейсе выводятся только при наличии проверенной рецептуры. Существующее поле nc в ноябрьском каталоге относится к предварительным данным, поэтому текущий результат не является подтверждением фактического потребления. Для выпуска с заявлением о 50 г подтвердить nc по источникам для каждой допускаемой рецептуры и сверить его с расчётом из ядра. Архивные рецептуры и их контрольные суммы сохранены.
- На экране обучения есть инструкция по приложению, состояния загрузки и различимые ошибки входа, прав или запроса. Добавлены четыре урока для рецензии владельцем. Полученные с сервера черновики остаются защищены действующим допуском. Причина сбоя открытия на телефоне требует проверки в Telegram.
- Календарная генерация использует доступный каталог целевого месяца и отдаёт приоритет новым для клиента блюдам при переходе с уже сохранённого меню. Приоритет проверен на тестовом каталоге, где 3 из 9 уникальных блюд были новыми. Результат с реальными ограничениями зависит от числа подходящих блюд. Полноценный просмотр всей истории месяцев остаётся открытым.
- Для k28 создана иллюстрация готового блюда на основании зафиксированного состава. Формат WebP, 960×640, 112026 байт. Иллюстрация включена в карточку и каталог и подписана в карточке. Для рецепта без изображения выводится сообщение «Фото блюда готовится».

## Состав каталога и допуск

Проверенный экспорт ноября содержит 36 записей, из них 20 кето. В этой ветке к шести из 20 кето-позиций привязаны изображения. Пять изображений существовали ранее, одно добавлено. Ни одной новой рецептуре не выдавался допуск. Ни одна из 20 кето-позиций этого экспорта не содержит подтверждённый расчёт по ингредиентам нового формата.

[Четыре новые рецептуры на пробную готовку и очередь следующих блюд](../content/2026-11-19-recipe-trial-drafts.md). Для 14 существующих кето-позиций нужны иллюстрации: k6, k7, k8, k9, k10, k11, k12, k13, k14, k15, k16, k17, k25, k27. Привязка фото к позиции не меняет статус ручного допуска рецепта. Публиковать новые рецептуры отдельной версией каталога после сверки исходной массы, выхода, аллергенов, пищевой ценности и изображения.

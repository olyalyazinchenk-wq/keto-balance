## 4. Готовые варианты запуска показа

### Вариант А. Локальный показ в браузере (готов прямо сейчас, без туннеля и токена)
Запуск командой:
```powershell
& ".venv-p0/Scripts/python.exe" scripts/run_local_preview.py --port 18080
```
И переход по ссылке в браузере:
👉 **`http://127.0.0.1:18080/?demo_user=1084557944`**

*Особенности:*
- Вход в 1 клик со сквозной эмуляцией сессии владельца (ID `1084557944`).
- Полный 4-экранный путь (настройки 18+, меню, замена блюд, рецепт с таймером, умные покупки, обратная связь).
- Полная локальная безопасность: не открывает порты наружу, не требует Telegram-бота и туннеля, таймер автовыключения 1 час.

### Вариант Б. Личный показ со смартфона через Telegram WebApp
Требует передачи токена тестового бота владельца (через безопасный файл) и запуска туннеля:
```powershell
# Запуск с файлом токена (исключает токен из списка процессов и логов PowerShell):
& ".venv-p0/Scripts/python.exe" scripts/run_staging.py --port 18080 --token-file <PATH_TO_TOKEN_FILE>
```
*Особенности:*
- Проверка реальной HMAC-подписи Telegram WebApp `initData`.
- Доступ только для вашего Telegram ID (`1084557944`), все остальные запросы получают HTTP 403 до создания пользователей в БД.
- Платежи выключены, таймер автовыключения 1 час.

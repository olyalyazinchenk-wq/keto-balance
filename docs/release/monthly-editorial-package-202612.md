## 1. Назначение и регламент допуска

В соответствии с правилами проекта КетоБаланс:
1. **Никакой автоматической публикации:** Ни один новый рецепт не попадает в публичный каталог без явной личной приёмки Ольгой.
2. **Неизменность истории (Immutability):** Пользователи, составившие меню в ноябре 2026 года по каталогу `released-catalog-202611-v1`, сохраняют в точности свои блюда, граммовки, замены и покупки из сохранённого снимка. Выход нового каталога не перезаписывает старые данные.
3. **Честный переход на новый месяц:** При наступлении декабря приложение предлагает создать новое меню из актуальной подборки декабря `released-catalog-202612-v1` либо продолжить текущий план.
4. **Разделение подходов:** Новые рецепты добавляются как в кето-линейку, так и в карнивор-линейку с раздельным аудитом аллергенов и нутриентов.

## 4. Процедура публикации утверждённого пакета

После письменного одобрения Ольгой:
1. Рецепты вносятся в `src/data/recipes.ts` и `src/data/releasedRecipeIds.ts` с хешами содержимого `sourceHash`.
2. Запускается верификатор `scripts/validate-catalog.mjs`.
3. Команда `npm run build` формирует неизменяемый артефакт `dist/released-catalog-202612-v1.json`.
4. Сервер `CatalogService` регистрирует новую версию и открывает доступ к ней в интерфейсе планирования на декабрь.

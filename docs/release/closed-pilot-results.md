## 2. Проверенные сценарии пользователя

| № | Сценарий | Механизм проверки | Результат | Подтверждающие улики |
|---|---|---|---|---|
| 1 | **Стартовый экран (Start Gate)** | Playwright E0 + Юнит-тесты | **PASS** | Чекбоксы 18+ и ПДн строго блокируют вход до выбора обоих (0/2, 1/2 -> кнопка disabled; 2/2 -> доступ открыт). Выбор подхода («Кето» / «Карнивор») корректно передаётся в форму настроек. |
| 2 | **Сохранение согласий на сервере** | Backend test_data_rights + TMA wireup | **PASS** | Эндпоинт `POST /api/user/consents` фиксирует дату, тип и источник согласия; `GET /api/user/data` возвращает их в составе GDPR-выгрузки. |
| 3 | **Каталог рецептов и замена блюд** | Playwright E1 + E2E food-flow | **PASS** | Все 42 рецепта проверены формулой КБЖУ, аллергенные фильтры строго исключают опасные ингредиенты (яйца, молочка, рыба). Замена блюда на лету пересчитывает список покупок. |
| 4 | **Синхронизация списка покупок** | Frontend + Backend CAS | **PASS** | Изменение множителя порций (1x/2x) и ручное добавление ингредиентов сохраняются на сервере. Отметка купленного в магазине (`checkedInStore`) не инвалидирует состояние меню. |
| 5 | **Аутентификация и изоляция данных** | Backend test_user_api + test_auth | **PASS** | Межпользовательский доступ строго заблокирован с HTTP 403. Токены сессий хранятся в БД исключительно в виде SHA-256 хэшей. |
| 6 | **Канал поддержки нутрициолога** | Playwright E3 + Bot integration | **PASS** | Кнопка «Написать Ольге» ведет на честный маршрут `@olga_diet_help` / бота с тегом вопроса. Никаких фальшивых тикетов или скрытых списаний не происходит. |

## Утверждённое направление
Один существующий KetoBalanceBot / @keto_balance_userbot, один продукт keto-balance, одна существующая ВМ. Новые боты, токены и серверы не создавать. OnSpace, Qwen и KetoPulse — отдельные версии, их готовность сюда не переносить.
Первый выпуск: кето, 18–20 проверенных блюд, меню 7 дней, замены, порции, покупки, сохранение/повторный вход, связь с Ольгой. Экспертное одобрение не подменять техническим статусом.
Рекомендация 12.11: первый платный пилот сопровождения с приложением, затем решение о подписке по использованию. Цена и календарная дата релиза не утверждены.

## Очередь до релиза
1. Сопоставить Windows-версию, GitHub и сервер; сохранить последнюю работу в отдельной ветке/PR без потери чужих изменений.
2. Зафиксировать source SHA, build ID, catalog hash и фактический deployed SHA. Сейчас deployed SHA = UNKNOWN.
3. Восстановить один рабочий бот, HTTPS и оба входа; подтвердить первый и повторный вход в настоящем Telegram.
4. Проверить ограничения, рецептуры/порции/покупки/сохранение/поддержку; согласия, доступ к данным, backup/restore.
5. Приёмка Ольгой интерфейса и рецептов; бесплатный пилот 5–10 человек; устранение критических ошибок.
6. Подготовить предложение, условия продажи, оплату и выдачу доступа; затем платный набор.

## Условия приёмки
Код в GitHub ≠ код на сервере; CI ≠ мобильная приёмка; локальный отчёт ≠ независимая проверка.
Готовность подтверждается на одном и том же SHA: сборка, сервер, реальный Telegram, повторный вход/сохранение, один бот, проверенный каталог, поддержка, backup/restore и приёмка владельцем.

## KPI пилота (предлагаемые определения; фактических значений пока нет)

Источник данных будущего пилота: **локальный обезличенный журнал тестовых сценариев** с timestamp, кодом сценария и статусом, без ПДн/медицинских жалоб. Нельзя выводить показатели из количества тестов CI.

- **Доля выполненных сценариев** = выполненные без помощи / начатые ×100%; отдельно для входа, меню, замены, рецепта, покупок и восстановления после перезапуска, с абсолютным числителем/знаменателем.
- **Корректность аллергенов** = 1 − (число запрещённых рекомендаций / число проверенных замен и меню); **допустимый дефект — 0**, тестировать негативные профили отдельно.
- **Сохранение данных** = подтверждённые повторным открытием корректные изменения / предпринятые сохранения; ошибки/конфликты учитывать отдельно.
- **Доступность рациона** = профили, для которых построен разнообразный допустимый план / все проверенные профили, стратификация по режиму и исключениям; не считать формальное заполнение слотов успехом.
- **Завершение списка покупок** = сценарии с корректной группировкой, отметками, долями и синхронизацией / начатые сценарии покупок.
- **Критические инциденты, обращения и затраты**: отдельно счётчики; требование **0 критических** и **0 неразрешённых расходов**.

Численные доли и пороги успеха определяются после тестовой выборки и фиксации протокола; без данных не приписывать успех. Для малой выборки выводить `n/N` рядом с процентом, без статистически необоснованных выводов.

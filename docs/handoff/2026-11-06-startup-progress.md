# КетоБаланс: запуск и порции — промежуточная передача

## Observation
6 ноября 2026 в Telegram Web открыт существующий бот @keto_balance_userbot. Кнопка меню открыла Mini App с ответом `no tunnel`: адрес кнопки устарел. Подписанные данные запуска не сохранялись. Это подтверждает причину сбоя проверенной кнопки, а не всех исторических пустых экранов.

Изменено локально: подписи выхода/масштабирования берутся из yieldNote; k5 переименован по составу; тестовый audit перенаправлен во временную папку; migration-bundle и проверка локального пилота изолированы в тестах. Удалены четыре собственные тестовые записи из журнала.

Страница содержит статическое сообщение загрузки. Убраны Google Fonts. SDK Telegram загружается асинхронно с пределом ожидания 5 секунд. Сетевой клиент ограничивает соединение и чтение ответа 10 секундами, не повторяет записи автоматически. Получение подписки больше не блокирует меню.

## Logic Chain
Ошибка туннеля возникает до загрузки приложения. Обновления исходников сами по себе не исправляют устаревшую кнопку Telegram. Рабочий сервер и его кнопки пока не переключались.

## Caveats
Полная редакторская проверка 50 заготовок не завершена; допуск к выпуску не выдавался. Нужны дополнительные проверки отказа SDK и отображения ошибки сети в браузере. Реальный повторный вход с исправленной сборкой не проверен. Данные и тарифы не менялись.

## Conclusion
Локальная регрессия пройдена; готовность рабочего Telegram-запуска пока не подтверждена. Следующий этап: редакторский пакет каталога, отрицательные сценарии загрузки, единая квитанция сборки и проверяемое исправление адреса кнопки владельца.

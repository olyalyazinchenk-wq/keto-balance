## 3. Спецификация для облачного исполнителя (`84.54.56.73`)

### 3.1. Получение релизного кода
На сервере в каталоге проекта выполнить подтягивание коммита `9343f7d`:
```bash
git fetch origin feat/telegram-miniapp-launch-safety-20261105
git checkout 9343f7d
```

### 3.2. Конфигурация окружения `.env.production`
Создать файл `.env.production` со следующими параметрами:
```env
APP_STAGE=production
WEBAPP_DOMAIN=keto-84-54-56-73.sslip.io
TELEGRAM_BOT_TOKEN=<СУЩЕСТВУЮЩИЙ_ТОКЕН_KETO_BALANCE_USERBOT>
KETO_LOAD_DOTENV=0
KETO_DB_PATH=/app/data/keto_balance.db
KETO_DIST_DIR=/app/dist
PAYMENT_MODE=disabled
PAYMENTS_ENABLED=0
TELEGRAM_WEBHOOK_SECRET_TOKEN=keto_prod_secret_token_2026
```
*(Если прямой доступ к `api.telegram.org` из ДЦ Cloud.ru блокируется, добавить `KETO_BOT_PROXY=http://...`)*.

Установить права доступа:
```bash
chmod 600 .env.production
```

### 3.3. Запуск контейнеров через Docker Compose
В каталоге `deploy/` запустить стек:
```bash
docker compose -f compose.yml --env-file ../.env.production up -d --build
```

Архитектура контейнеров (`deploy/compose.yml`):
- `caddy` (Caddy 2): Автоматический HTTPS-сертификат Let's Encrypt для `keto-84-54-56-73.sslip.io`, порты 80/443. Лимит RAM: 200M.
- `web` (FastAPI + Vite SPA): Порт 8000 (внутренний), раздача SPA, валидация initData, API меню и покупок. Лимит RAM: 700M.
- `bot` (Python long-polling): Единый процесс опроса Telegram API, команды, поддержка `/start=question`. Лимит RAM: 500M.
- Суммарный лимит RAM: 1.4 ГБ (гарантированно укладывается в 2 ГБ / 4 ГБ ВМ).

### 3.4. Привязка Mini App к боту в @BotFather
После получения SSL-сертификата в Caddy обновить URL кнопки меню в `@BotFather`:
1. Открыть диалог с `@BotFather`.
2. Ввести `/mybots` → Выбрать `@keto_balance_userbot`.
3. Перейти: **Bot Settings** → **Menu Button** → **Configure menu button**.
4. Указать URL: `https://keto-84-54-56-73.sslip.io`.
5. Текст кнопки: `Открыть КетоБаланс` (или `Меню и рецепты`).

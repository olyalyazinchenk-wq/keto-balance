# Selectel Cloud — выбранное направление, 4 ноября 2026

**Состояние:** пользователь выбрал регистрацию в Selectel Cloud после недоступности Beget и препятствий с SmartApe / Айтеко.Cloud. Аккаунт Selectel из текущего чата не открыт и не создан; сервер, домен, DNS и Telegram-кнопки не менялись. Заявка Timeweb Cloud на тестовые бонусы ранее отправлена, но это отдельный запасной вариант.

## Где регистрироваться

- Прямая официальная форма: https://selectel.ru/registration/
- Панель после регистрации: https://my.selectel.ru/
- Официальная инструкция для физлиц: https://docs.selectel.ru/account/registration/

Выбрать **Личный аккаунт (физическое лицо)**, если нет ИП или юрлица. Тип аккаунта позже поменять нельзя. Подтвердить почту и телефон. По документации 07.10.2026 требуется минимально пополнить **200 ₽**, чтобы пользоваться услугами; деньги остаются на балансе, но расходы по ресурсам начисляются почасово. На этом этапе не переводить деньги и не создавать сервер, пока цена и условия не согласованы.

## Точный продукт

**Облачные серверы / Cloud Standard Line**, НЕ «VDS by Selectel» за 400–650 ₽. Официальная документация утверждает, что облачные серверы и бэкапы по расписанию отвечают требованиям 152-ФЗ до УЗ-1 в зоне ответственности провайдера; ответственность за безопасность ОС, приложения, сети и доступов на клиенте. Соответствие инфраструктуры включено в цену, поручение на обработку данных оформляется по тикету. Если потребуется именно обязательная аттестация системы или изолированная среда, обсудить «Аттестованное облако».

- Соответствие: https://docs.selectel.ru/cloud-servers/about/152-fz-cloud-server/
- Тарифы: https://selectel.ru/services/cloud/servers/?section=prices (Standard Line «от 948,50 ₽/мес.» — не финальный полный чек)
- Процедура создания: https://docs.selectel.ru/cloud-servers/create/create-server/
- Статус площадок: https://selectel.live/ (4 ноября: проблемы ru-7a/ru-7b, выбирать только проверенно работоспособный регион и пул).

Для запуска Keto Balance ориентир: одна Ubuntu 24.04 LTS VM, 1–2 vCPU, 2 GiB RAM, сетевой диск 20–30 GiB, ровно один IPv4, HTTPS reverse proxy; нужно подтвердить цену каждой составляющей, включая резервирование. Не включать платные панели и дополнительные услуги без согласования. Один Telegram bot poller, React/Vite production build, FastAPI, SQLite в отдельном постоянном томе, оплаты отключены.

## Контроль рисков

- Пользователь не приобретал домен. Не подменять его временным tunnel URL; для обеих Telegram кнопок нужен один проверенный стабильный HTTPS origin, долгосрочное имя согласовывать отдельно.
- Из последних актуальных исходников Terra/Antigravity сохранить дневной совет и другие локальные изменения; GitHub master от 27 октября старее. Черновик инфраструктуры — PR #16, не объединять без сверки.
- До проверки защиты, поручения обработки, законного основания обработки данных о здоровье, возможных уведомлений РКН, резервного копирования и удаления — только синтетические данные.
- По модели оплаты Selectel сервер и другие ресурсы могут списывать почасово даже при остановке VM; контроль бюджета обязателен.

**Следующий шаг:** пользователь самостоятельно проходит обязательное подтверждение телефона и почты в официальной форме, либо в Work-режиме использует браузер; затем технический агент проверяет реальную стоимость и бонусы в кабинете. Платные ресурсы до согласования не создавать.

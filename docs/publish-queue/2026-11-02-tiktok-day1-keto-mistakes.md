```

#кето #ошибки #завтрак #кетодиета #низкоуглеводное
```

Замечания по редполитике `docs/CAPTIONS-AND-CALENDAR.md`:
- для внешних площадок призыв должен называть канал → рекомендуется добавить `@olga_nutri_med` («Чек-лист — продолжение в канале @olga_nutri_med»);
- TikTok лучше принимает 3–4 тега (9+ — худший результат), сейчас 5: рабочий минимум `#кето #ошибки #завтрак`, остальные — по желанию.

## 3. Почему публикация не выполнена (проверено)

| Проверка | Результат |
|---|---|
| Сессия TikTok в браузере Hermes (чистый профиль) | `tiktok.com/upload` → редирект на `/login` |
| Chrome, профиль Default | только cookie `_ttp` (трекинг), входа нет |
| Chrome, профиль Profile 2 | только cookie `_ttp`, входа нет |
| Yandex Browser / Opera | cookie TikTok отсутствуют |
| Хранилище логинов Hermes (`browser_vault`) | пусто (0 записей) |
| Публичный аккаунт TikTok для `@olga_nutri_med` | не найден поиском |

Дополнительно: локальный режим браузера Hermes с профилем владельца недоступен — браузер по умолчанию не Chromium (`real_profile_unavailable`). Поэтому даже после входа в Chrome браузерный агент пока не сможет использовать этот профиль без отдельной настройки.

Из РФ TikTok ограничивает загрузку нового контента — при публикации нужен рабочий VPN (Happ, http 127.0.0.1:10809).

## 4. Как разблокировать (в порядке простоты)

1. **Публикация с телефона (1 минута):** переслать себе файл `keto-mistakes_teaser_tiktok.mp4` и текст из раздела 2, загрузить из приложения TikTok.
2. **Вход в Chrome (даёт автоматизацию в будущем):** один раз войти в TikTok в Chrome, желательно в отдельном профиле «Keto», с включённым Happ. После этого — отдельная задача: подключить Hermes к профилю Chrome (CDP) и проверить загрузку тестовым черновиком.
3. Ничего не публиковать, если аккаунта ещё нет — создание аккаунта и принятие условий TikTok остаются решением владельца.

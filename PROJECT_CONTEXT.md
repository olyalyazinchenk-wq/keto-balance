## 4. Пульт управления Agent-First: scripts/agent_ops.py

Все рутинные действия автоматизированы через единую утилиту `scripts/agent_ops.py` (или `ops/agent-ctl.ps1`):

### Уровень AUTONOMOUS (выполняется агентами самостоятельно):
- `status`: проверка локального пилота, изоляции NutriOK, чистоты Git и статуса биллинга (выводит `UNKNOWN`, если биллинг не опрошен).
- `diagnose`: проверка сетевой связности с `api.telegram.org` и `iam.api.cloud.ru`.
- `cloud-audit`: опрос 11 сервисов Cloud.ru Evolution через `scripts/cloudru_teardown.py --audit-only`.
- `backup-drill`: тестовый цикл бэкапа и восстановления синтетической базы.
- `sync-status`: динамическое обновление `docs/LIVE_STATUS.md` на основе реально выполненных проверок текущего коммита.
- `credentials status|clear`: управление учётными данными в защищённом хранилище `.secrets/`.
- `migration-bundle`: генерация независимого пакета миграции на Yandex Cloud / VPS (`deploy/docker-compose.migration.yml`).

### Уровень GUARDED (требует явного подтверждения владельца):
- `grant-activate`: активация гранта Cloud.ru.
- `deploy-live`: развёртывание на боевом сервере.
- `destroy-cloud`: удаление ресурсов в облаке.
- `publish-app`: перевод бота в публичный режим.
*Внимание:* флаг `--confirm-phrase "СОГЛАСОВАНО ОЛЬГОЙ"` или approval token является **клиентским предохранителем от случайного запуска**, а не криптографическим доказательством полномочий. Любое рискованное действие предварительно согласуется с Ольгой лично.

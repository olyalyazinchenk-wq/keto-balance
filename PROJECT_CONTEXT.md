## 3. Пульт автономного управления: scripts/agent_ops.py

Все рутинные операции стандартизированы через единую утилиту `scripts/agent_ops.py` (или `ops/agent-ctl.ps1` для Windows):

### Разрешено агентам выполнять автоматически (Tier: AUTONOMOUS):
| Команда | Описание |
|---|---|
| `python scripts/agent_ops.py status` | Экспресс-проверка статуса системы, пилота, ветки Git и нулевых расходов. |
| `python scripts/agent_ops.py diagnose` | Проверка сетевой связности с Telegram Bot API и Cloud.ru IAM. |
| `python scripts/agent_ops.py cloud-audit` | Полный аудит всех 11 сервисов Cloud.ru Evolution и биллинга (через `cloudru_teardown.py`). |
| `python scripts/agent_ops.py backup-drill` | Неразрушающий цикл бэкапа и тестового восстановления синтетической БД (AES-256-GCM). |
| `python scripts/agent_ops.py credentials status` | Проверка наличия ключей доступа в защищённом хранилище `.secrets/`. |
| `python scripts/agent_ops.py migration-bundle` | Генерация пакета экстренного переноса на Yandex Cloud или VPS (`deploy/docker-compose.migration.yml`). |

### СТРОГО требует отдельного разрешения Ольги (Tier: GUARDED):
- `grant-activate` — активация гранта и привязка карты (финансовые риски после 60 дней).
- `deploy-live` — развёртывание на внешнем боевом сервере.
- `destroy-cloud` — физическое удаление облачных ресурсов.
- `publish-app` — публичный запуск бота для пользователей.
*Любая попытка запуска этих действий без флага `--owner-approved` блокируется автоматически.*

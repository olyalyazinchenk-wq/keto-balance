## Детерминизм и данные
- Повторяемые вычисления и проверки выполняй кодом, а не рассуждениями LLM.
- Калории, БЖУ, чистые углеводы, доли макронутриентов и электролиты рассчитывай только через покрытый тестами src/core/keto-engine/.
- Пока keto-engine не реализован и не проверен, не выдавай его расчеты как готовые.
- Формулы, единицы, учет клетчатки и полиолов, цели питания требуют утвержденной спецификации.
- Неизвестные или непроверенные БЖУ и цены помечай [УТОЧНИТЬ]; не выдумывай значения.

## Argon (Google AI Studio) и GitHub
- Песочница дизайна: `olyalyazinchenk-wq/Keto-Balance_Argon-4`. В основной `keto-balance` Argon не пишет.
- В AI Studio включена двусторонняя синхронизация. Изменения уходят кнопкой **«Отправить изменения в GitHub»** во вкладке GitHub; нажимать её без отдельного согласования разрешено, но только для песочницы.
- После отправки: `node scripts/argon-pull.mjs --no-build` — подтягивает актуальные ассеты и код из дизайн-песочницы Argon (`7c4874a9`), показывает git diff и не ломает пайплайн предварительной сборкой. Полная изолированная сборка выполняется отдельно через `node scripts/build-isolated.mjs --json`. Результат сообщать фактами, а не «должно работать».
- Одноразовые коды, пароли, CVC и 2FA-подтверждения агент **не вводит и не принимает в чате** — даже по просьбе владельца. Если GitHub требует sudo, открыть окно и передать владельцу: подтверждение занимает секунды.
- ZIP-версии из AI Studio — резервный канал; импорт: `node scripts/import-argon-version.mjs <zip>`.
- В `master` основной ветки ничего из песочницы не попадает без отдельного согласования: только ветка и проверка.

# Карта экранов и пользовательских сценариев (`docs/design/flows.md`)

Дата фиксации: 28 октября 2026 года  
Продукт: **«Кето Баланс»**

---

## 1. Сквозной основной сценарий

```text
[1. Начало (start)]
   ├─ (Отметка 18+ + выбор «Кето» или «Карнивор») ──► [2. Настройки (settings): Шаги 1 → 2 → 3]
   ├─ («Просто осмотреться без анкеты») ───────────► [3. Сегодня (today): режим ознакомления]
   └─ («Написать Ольге» до анкеты) ────────────────► [8. Поддержка (support)] ──(Назад)──► [1. Начало]

[2. Настройки (settings)]
   ├─ (Автосохранение черновика в localStorage на каждом шаге)
   ├─ («Написать Ольге» с любого шага) ────────────► [8. Поддержка (support)] ──(Назад)──► [Возврат на тот же шаг 1/2/3 с черновиком]
   └─ (Основная CTA «Выбрать меню») ───────────────► [4. Меню (menu)]

[3. Сегодня (today)]
   ├─ Состояние A: Первый визит (меню ещё не выбрано)
   │    ├─ Основная CTA «Выбрать меню» ────────────► [4. Меню (menu)]
   │    └─ Вторичная кнопка «Настроить ограничения» ► [2. Настройки (settings)]
   └─ Состояние B: Меню выбрано
        ├─ Основная CTA «Начать готовить» ─────────► [5. Рецепт и готовка (recipe)]
        ├─ «Собрать покупки» ──────────────────────► [6. Покупки (shopping)]
        └─ «Записать приём пищи» ──────────────────► [7. Ручной дневник (diary)]

[4. Меню (menu)]
   ├─ Переключение Дня 1 / Дня 2 / Дня 3
   ├─ «Заменить блюдо» (модальное окно выбора из подходящих по фильтру блюд)
   │    └─ При замене блюда помечает список покупок флагом `shoppingNeedsRefresh = true`
   ├─ «Рецепт и готовка» ──────────────────────────► [5. Рецепт и готовка (recipe)]
   ├─ Основная CTA «Собрать покупки» ──────────────► [6. Покупки (shopping)]
   └─ Конфликт ограничений (0 подходящих блюд)
        └─ Честное объяснение причины без тихого снятия фильтра аллергии + кнопка «Изменить настройки ограничений»

[5. Рецепт и готовка (recipe)]
   ├─ Переключение предзаданных вариантов «1 порция» / «2 порции» (из фикстуры, без автопересчёта БЖУ)
   ├─ Отметка чекбоксов ингредиентов и шагов (сохраняются в localStorage при выходе с экрана)
   └─ Основная CTA «Записать приём пищи в дневник» ─► [7. Ручной дневник (diary)]

[6. Покупки (shopping)]
   ├─ Группировка по 4 отделам магазина
   ├─ Переключатель «Уже есть дома» и отметка покупки в магазине
   ├─ Плашка «Меню было изменено» (если после формирования списка менялось блюдо в меню) + кнопка «Обновить список по меню»
   └─ Основная CTA «Скопировать список» (копирует только текст в буфер обмена без сетевых запросов)

[7. Ручной дневник (diary)]
   ├─ Выбор даты (по умолчанию пустой день действительно пустой — 0 записей)
   ├─ Основная CTA «Записать приём пищи» (свободный текст еды + необязательная заметка о сытости/самочувствии)
   └─ Редактирование и удаление собственных записей без оценок «идеальности» и без блокировки при неизвестном БЖУ (`[УТОЧНИТЬ]`)

[8. Поддержка Ольги (support)]
   ├─ Постоянная плашка «Демонстрация: сообщения не отправляются»
   ├─ Выбор темы вопроса и поле текста (сохраняется на экране при ошибке сети)
   ├─ Основная CTA «Написать Ольге в боте»
   ├─ Интерактивный переключатель состояний транспорта: `idle` | `pending` | `confirmed` | `failed` | `unknown`
   └─ Кнопка возврата («Вернуться к шагу N анкеты» / «Вернуться назад»)

[9. Ещё и материалы (more)]
   ├─ Полный каталог рецептов (8 блюд) с переходом в [5. Рецепт и готовка]
   ├─ Справочные памятки с указанием источника и статуса проверки
   ├─ Управление приватностью и сброс локальных данных (`localStorage`)
   └─ Переходы в [2. Настройки], [8. Поддержка] и [10. Предложение доступа]

[10. Предложение доступа (access)]
   ├─ Сравнение: Бесплатный пример (0 ₽) / Разовый стартовый продукт (`[УТОЧНИТЬ]`) / Подписка (`[УТОЧНИТЬ]`)
   ├─ Отдельная ограниченная услуга: Личное сопровождение Ольги (`[УТОЧНИТЬ]`)
   └─ Явная гарантия: ручной дневник, настройки приватности и отмена подписки никогда не блокируются
```

## 2. Таблица экранов, состояний и обработчиков возврата

| ID экрана | Название в UI | Основная CTA смыслового блока | Пустые / граничные состояния | Поведение кнопки «Назад» |
| :--- | :--- | :--- | :--- | :--- |
| `start` | Начало | `Выбрать меню под себя` | Попытка продолжить без отметки 18+ показывает спокойное предупреждение `role="alert"`. | Корневой экран при старте |
| `settings` | Настройки | `Выбрать меню` | Режим `explore` поясняет, что показывается общий пример меню; напоминания по умолчанию `false`. | Возвращает на предыдущий экран стека (`start` или `menu`) без потери черновика |
| `today` | Сегодня | До выбора меню: `Выбрать меню`; после выбора: `Начать готовить` | Переключатель «Первый визит (до выбора меню)» / «Меню на день выбрано»; переключение композиции `A` и `B`. | Возвращает по стеку `navStack` |
| `menu` | Меню | `Собрать покупки` | При 0 подходящих блюд (или кнопке «Проверить пустой результат») выводит честную причину и кнопку перехода к настройкам; не снимает фильтр аллергии. | Возвращает по стеку `navStack` |
| `recipe` | Рецепт и готовка | `Записать приём пищи в дневник` | БЖУ помечено как `[УТОЧНИТЬ]`; варианты на 1 и 2 порции берутся из предзаданной фикстуры; прогресс шагов сохраняется. | Возвращает в `Меню` или `Сегодня` с сохранением отмеченных шагов |
| `shopping` | Покупки | `Скопировать список` | Если в `Меню` заменили блюдо, появляется баннер `«Меню было изменено»` с кнопкой обновления. | Возвращает по стеку `navStack` |
| `diary` | Ручной дневник | `Записать приём пищи` | Изначально пустой день содержит честное пустое состояние без демо-записей; пустая отправка формы валидируется. | Возвращает по стеку `navStack` |
| `support` | Поддержка Ольги | `Написать Ольге в боте` | Демо-плашка; 5 состояний транспорта (`idle`, `pending`, `confirmed`, `failed`, `unknown`); ошибка не стирает введённый текст. | Возвращает точно на тот экран и шаг анкеты, откуда пришёл пользователь |
| `more` | Ещё и материалы | Переходы по карточкам разделов | Двухшаговое подтверждение очистки локальных данных `localStorage`. | Возвращает по стеку `navStack` |
| `access` | Предложение доступа | `Узнать условия старта` | Все неутверждённые тарифы помечены `[УТОЧНИТЬ]`; локальное уведомление при выборе тарифа. | Возвращает в `Ещё` или предыдущий экран |
